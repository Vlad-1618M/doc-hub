Internal Records & Document Hub

HR, teams, and internal data in one place.

What is this for?

  • HR & Employee Records — Resumes, profiles
  • Team Data — Research, IT, Marketing, work logs
  • Internal Documents — Centralized doc server
  • Secure — Stays inside your infrastructure

How data flows

User (Browser)
Submits login / form data via HTTPS request
React UI + nginx
Renders SPA, proxies /auth & /resume to FastAPI backend
FastAPI
JWT auth, Pydantic validation, CRUD endpoints
MongoDB
Stores users, resumes, api_keys as documents
