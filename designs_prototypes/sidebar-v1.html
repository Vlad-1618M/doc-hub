How data flows

STEP 1
User (Browser)
Submits login or form data via HTTPS
STEP 2
React UI
Renders SPA, proxies /auth & /resume to backend
STEP 3
FastAPI
JWT auth, validates requests, CRUD logic
STEP 4
MongoDB
Stores users, resumes, API keys (documents)
