How data flows

1
User
Submits login or form data over HTTPS from browser
2
React UI
Renders SPA; nginx proxies /auth & /resume to FastAPI
3
FastAPI
JWT auth, input validation, CRUD handlers
4
MongoDB
Document store for users, resumes, api_keys
