# New feature roadmap (org-aware platform)

This folder tracks **planned** work to grow Doc Hub from a document/resume hub into an **organization-aware** internal platform (taxonomy, ownership, access, and domain modules).

Use it for **prioritization and TODO tracking**—not as committed delivery dates.

| Document | Purpose |
|----------|---------|
| [ROADMAP.md](ROADMAP.md) | Phased features, tech prerequisites, testing & CI/CD per feature |

## How to track as TODOs

- **GitHub Issues:** create one issue per feature id (e.g. `F-1.1 Org unit model + CRUD API`) and label `roadmap` + phase (`phase-1`, …).
- **Projects:** add a “Roadmap” view; columns = phases or statuses.
- **Local checklist:** copy checkboxes from [ROADMAP.md](ROADMAP.md) into your issue body.
